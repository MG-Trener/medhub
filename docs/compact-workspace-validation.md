# Компактное рабочее окно врача

Ветка создаётся от `dev`. Исходное задание: [compact-workspace-prompt.md](compact-workspace-prompt.md).

## Изменения

- Консультация: ограниченная высотой окна рабочая область, вкладки медицинской записи, отдельная секция ИИ и отдельная вкладка аудио.
- Длинные тексты доступны по страницам; изменение страницы сохраняет остальной текст. Списки пациентов, приёмов, документов и результатов поиска диагнозов также имеют пагинацию.
- Карта пациента: вкладки приёмов, персональных данных и согласий. Создание пациента разделено на два шага.
- Убраны кнопки источников «Реплика» и индивидуального дополнения ИИ; добавлена общая перегенерация.
- Перегенерация сохраняет заполненные клинические поля: отличающиеся предложения остаются в предупреждениях ИИ для проверки врачом.
- Внутренний выход из консультации требует подтверждения с сохранением и завершением приёма. Закрытие и обновление страницы используют стандартное предупреждение браузера; браузер не позволяет задать ему произвольный текст.
- Незавершённый приём отображается после входа, повторный запуск открывает существующий приём. Добавлено автосохранение после правок при отсутствии записи и обработки.

## Проверки

- `cd frontend && pnpm build` — успешно.
- `cd frontend && pnpm test` — 18 тестов успешно.
- `cd backend && ../.venv/Scripts/python.exe -m pytest -q --basetemp ../artifacts/pytest-compact-final` — 144 теста успешно; перед запуском создать каталог `artifacts`.
- Локальный браузер: синтетические длинные тексты, 23 пациента, 21 приём, 30 фрагментов расшифровки. Проверены широкая и узкая компоновки, клинические вкладки, отдельная расшифровка, карта пациента, отмена выхода и завершение приёма с переходом.
- Размеры браузера для проверки: 870×880, 1020×880, 1366×768, 1440×900, 1920×1080. В проверенных рабочих панелях переполнение не обнаружено. Доступная высота страницы может быть меньше заданной высоты окна из-за панели браузера.

## Локальный просмотр

После сборки выполнить `node frontend/tests/preview-server.mjs` и открыть `http://127.0.0.1:5180`. Сервер содержит только синтетические данные и часть API для проверки интерфейса; не подключать его к рабочей базе и не использовать при деплое.

Физический микрофон, внешние AI API, NCALayer и SIGEX в браузерной проверке не использовались. Их реальные интеграции требуют отдельного стенда. Снимки и временные файлы проверок находятся в игнорируемом каталоге `artifacts` и не публикуются в Git.

На очень малой высоте окна и при увеличении текста приоритет отдан доступности содержимого. Просмотр PDF и настройки приложения не ограничены высотой основного медицинского рабочего окна.
