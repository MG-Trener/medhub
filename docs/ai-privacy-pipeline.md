# Конвейер и границы доверия

```mermaid
flowchart TD
  A[Браузер: согласие и запись] --> B[MedHub: зашифрованное хранение]
  B --> C[Доверенный локальный ASR: RU / KK / mixed]
  C --> D[Маскирование целого диалога и клинического контекста]
  C --> E[Заглушение реплик с идентификаторами]
  D --> F[Второй локальный NER-проход; ошибка блокирует внешний анализ]
  E --> H0[Необязательное прослушивание обезличенного WAV]
  F --> G[Локальная или API LLM: только обезличенные данные]
  H0 --> H[Необязательный внешний ASR: только проверенный заглушенный WAV]
  G --> I[Валидация схемы и точных цитат]
  I --> J[Черновик: ручные поля защищены]
  J --> K[Врач проверяет и подтверждает версию]
  K --> L[PDF / МИС: только клинические поля]
```

Доверенный ASR — процесс на сервере, локальном ПК или специально назначенном GPU-ПК через приватный туннель. Self-hosted не означает автоматически безопасный: оператор обязан контролировать его хранение, журналы, ключи и сетевой доступ. Перенаправления HTTP отключены. Облачные ключи не наследуются другими провайдерами.

Идентификационная карточка и медицинский контекст разделены. Перед внешней LLM автоматически проверяется отправляемый набор данных, включая отредактированные врачом поля. Требуются согласие и локальный NER-проход, но не ручная проверка врачом. Подписанное согласие не отключает защиту. GLiNER загружается из локального каталога, длинный текст обрабатывается перекрывающимися окнами; сомнительные реплики, обнаруженные только в объединённом контексте, исключаются целиком. Ответы пациента проходят ту же границу.

Если ASR или NER недоступен, данные остаются внутри контура и облачная генерация не выполняется. Облачный ASR не входит в основной рабочий поток: это отдельное необязательное уточнение уже заглушённой записи после прослушивания. Запросы к локальной LLM также детерминированно обезличиваются.

Автоматическая вырезка имён в свободной речи ограничена качеством ASR. Если имя не распознано или сказано без маркера, его может не обнаружить детектор. Нельзя заявлять гарантированное обезличивание. Вырезаем целые реплики с временным запасом, потому что точные границы отдельных слов могут ошибаться; оригинал хранится зашифрованно внутри контура и доступен уполномоченному врачу.

Возраст и пол передаются отдельными медицинскими признаками без даты рождения и ИИН. Сексуальный анамнез и заболевания считаются медицинскими данными, сохраняются для анамнеза при наличии согласия; они не должны попадать в технические журналы. Внешние проверки — исключительно синтетические данные.
