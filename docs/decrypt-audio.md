# Локальная расшифровка архива аудио

`scripts/decrypt_audio.py` снимает шифрование Fernet с локальной копии файлов
`*.enc`. Распознавание речи не запускается, БД и внешние AI API не используются.
Исходные файлы остаются без изменений. Используется ключ `ENCRYPTION_KEY` того
окружения, в котором были сохранены записи.

1. Скопируйте каталог `AUDIO_DIR` нужного сервера в `data/audio-encrypted`.
   При текущей схеме systemd серверный каталог — `/opt/medhub/shared/audio`.
2. Используйте локальный закрытый env-файл с соответствующим ключом. Не
   передавайте ключ аргументом командной строки и не добавляйте его в Git.
3. Выполните из корня проекта в PowerShell:

```powershell
.venv/Scripts/python.exe scripts/decrypt_audio.py --env-file .env.production --input data/audio-encrypted --output data/audio-decrypted
```

Если `--env-file` не указан, ключ читается из переменной окружения
`ENCRYPTION_KEY`. Зависимости `cryptography` и `python-dotenv` входят в окружение
backend. Входная и выходная папки должны быть отдельными, без вложения друг в друга.

Скрипт рекурсивно обрабатывает весь архив: полные записи, фрагменты и маскированные
копии, если они присутствуют. Фрагменты не склеиваются, копии не удаляются.
Имена файлов сохраняются, расширения WAV, WebM, Ogg, FLAC, MP3 и MP4 определяются
по заголовку. Неизвестный формат сохраняется с расширением `.bin`, без конвертации.
Связь файла с приёмом хранится в зашифрованном `jobs.payload` в БД; этот скрипт
не извлекает ФИО и другую информацию о пациентах.

В выходной папке создаётся `manifest.json`: исходный и итоговый путь, число байтов,
SHA-256 и результат обработки. При повторном запуске совпадающие файлы пропускаются;
отличающиеся не перезаписываются. Неверный ключ или повреждённый файл отмечается
ошибкой, обработка остальных файлов продолжается. Код завершения `0` означает,
что все файлы выгружены или уже присутствуют; `1` — ошибки. Пустой архив также
считается ошибкой.

Результат содержит незашифрованное аудио. Храните его в папке с доступом только
для уполномоченных пользователей. Каталог `data/` исключён из Git, в том числе
аудио и отчёт. На Windows права доступа наследуются от родительской папки;
на POSIX новые папки создаются с правами `700`, файлы — `600`.

Проверка на синтетических файлах:

```powershell
.venv/Scripts/python.exe -m unittest discover -s scripts -p test_decrypt_audio.py
```
